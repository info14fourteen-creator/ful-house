**Goal:** Give the existing model persistent instructions and scoped coding/deployment tools; diagnose startup latency.
**Architecture:** Open WebUI Python tool adapter calls an admin-only server broker. Non-root commands run over pinned SSH on the existing persistent GPU volume. GitHub API handles branches/commits/PRs; Actions deploys the fixed app/project with repository secrets.
**Tech Stack:** Python/httpx/asyncio, Open WebUI 0.11.3, GitHub Actions, SSH, existing Runpod/Heroku/Cloudflare.
**Spec:** docs/superpowers/specs/2026-09-19-engineer.md
