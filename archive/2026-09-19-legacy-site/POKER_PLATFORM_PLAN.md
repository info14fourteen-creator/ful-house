# Poker AI Platform Plan

Дата: 2026-07-05
Проект: редизайн текущего сайта Фулхаус в темную покерную платформу с AI-диагностикой уровня, обучением, статьями, RSS и турнирным контентом.

## Дизайн-бриф

Сайт должен сразу давать действие: "сыграйте несколько раздач, мы поймем ваш уровень и соберем программу обучения". Визуально ближе к черному: глубокий фон, зеленое сукно, красные/золотые акценты, плотный интерфейс, ощущение poker room + training lab. Это не казино и не сайт ставок: первая версия должна быть play-money / educational.

## Основной продуктовый сценарий

1. Пользователь заходит на главную.
2. Видит интерактивный покерный стол и кнопку "Определить мой уровень".
3. Выбирает формат: новичок, уже играл, проверить без подсказок.
4. Играет 10-20 диагностических раздач против AI-агентов.
5. Система оценивает решения: preflop, позиция, агрессия, fold discipline, pot odds, postflop-логика, ошибки на опасных досках.
6. Пользователь получает уровень, стиль игры, 3 главные ошибки и персональный маршрут.
7. Дальше идет цикл: урок -> мини-тест -> 5 тренировочных раздач -> разбор AI -> следующий блок.

## Целевые платформы

Планируем не только сайт. Продукт должен развиваться как единая система для четырех поверхностей:

- Desktop web: основная версия с полным столом, диагностикой, статьями, RSS, турнирами и личным планом.
- Mobile web: удобная вертикальная версия, где карты, действия, банк, подсказки и статьи не перекрываются.
- Telegram Mini App: быстрый вход, короткая диагностика, daily hand challenge, уведомления и переход к урокам.
- macOS app: desktop-приложение в духе утилитарного рабочего инструмента, как Tronix Rent: быстрый запуск тренировок, история сессий, AI-стол и личный план.

Подробные требования: `docs/platform-targets.md`.

## Уровни игроков

0. First Hand: не знает комбинации и порядок торговли.
1. Beginner: знает правила, играет хаотично.
2. Recreational: играет по ощущениям, часто коллирует.
3. Intermediate: понимает позиции, базовые диапазоны и value bet.
4. Advanced: думает диапазонами, видит multi-street plan.
5. Grinder: системно играет cash/MTT, нужны солверные и ICM-споты.
6. Pro Lab: разбор сложных линий, exploit vs GTO, database review.

## AI-агенты

- Game Engine: колода, ставки, банк, правила, победитель. Только детерминированная логика.
- Skill Evaluator: оценивает решения игрока и присваивает уровень.
- Curriculum Agent: собирает персональный учебный маршрут.
- Coach Agent: объясняет ошибки после раздачи.
- Beginner Bot: слабый и понятный соперник.
- Calling Station Bot: часто коллирует, учит value betting.
- Tight Regular Bot: играет узко и дисциплинированно.
- Aggressor Bot: давит ставками, проверяет tilt resistance.
- GTO-ish Bot: играет близко к сбалансированной стратегии.
- Tournament Bot: проверяет ICM, short stack, push/fold.
- Safety Agent: не допускает обещаний заработка, следит за responsible play.

## Страницы

- Главная: темный стол, диагностика уровня, быстрый вход в игру.
- Диагностика: 10-20 раздач, HUD решений, прогресс оценки.
- Результат уровня: уровень, стиль, ошибки, сильные стороны, next best lesson.
- Личный план: карта обучения по модулям и прогресс.
- Тренажер раздач: сценарии preflop/postflop/turn/river.
- AI-стол: play-money игра с разными агентами.
- Библиотека: правила, комбинации, позиции, диапазоны, odds, bankroll.
- Стратегия: beginner/intermediate/advanced/grinder материалы.
- Турниры: календарь, новости, форматы, заметки по MTT.
- Новости/RSS: агрегатор заголовков с источниками и ссылками.
- Статьи: собственные SEO-материалы и переводы/конспекты без копирования чужого текста.
- Глоссарий: термины покера.
- Ответственная игра: возраст, play-money, риски, отказ от обещаний дохода.
- О проекте: AI poker coach, mission, ограничения.
- Контакты/партнерство: авторы, тренеры, медиа, турниры.

## Контент и RSS

Подключать RSS и внешние ленты надо как источник ссылок и идей, а не как копирование статей. Для своего сайта нужны собственные тексты: обзоры, конспекты, объяснения, разборы турниров, учебные материалы.

Источники для мониторинга:

- PokerNews RSS: https://www.pokernews.com/rss/
- PokerNews live tournament calendar: https://www.pokernews.com/poker-tournaments/
- WSOP official site: https://www.wsop.com/
- WPT official site: https://www.worldpokertour.com/
- PokerNews podcast RSS: https://pokernews.libsyn.com/rss

## Архитектура MVP

Текущий проект статический. Для MVP можно начать со статического темного сайта с mock-диагностикой и локальной логикой на JS. Для настоящих AI-агентов нужна следующая стадия: Next.js/Node backend, база пользователей, API для hand history, evaluator service, content pipeline, RSS ingestion.

## Автоматизация выполнения

Оптимальный вариант: одна recurring automation на 72 запуска каждые 10 минут. Каждый запуск берет следующий невыполненный шаг из этого файла, делает только один 10-минутный инкремент, сверяется с уже сделанным, фиксирует результат в `POKER_PLATFORM_PROGRESS.md`, проверяет влияние на desktop web, mobile web, Telegram Mini App и macOS app, не пушит без явного разрешения и не подключает real-money функции.
